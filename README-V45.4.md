# أثر V45.4

## التعديلات

- حركة أكثر سلاسة لسهم بوصلة القبلة مع تقليل الاهتزاز.
- رمز واضح للكعبة في أعلى البوصلة.
- إظهار مقدار الانحراف يمينًا أو يسارًا.
- تصغير مساحة البوصلة وتحسين العرض على الهاتف.
- إبقاء اللون الأخضر والاهتزاز الخفيف عند الوصول إلى اتجاه القبلة.
- تحسين واجهة إشعارات الصلاة وإضافة زر اختبار.
- تجهيز Web Push لإرسال إشعارات الصبح والظهر والمغرب والمنصة مغلقة.

## مهم لتفعيل الإشعارات خارج المنصة

رفع موقع Next.js وحده لا يكفي. يجب نشر المجلد `athar-push-worker` كـ Cloudflare Worker، إنشاء KV باسم `PUSH_STORE`، ثم إضافة رابط الـ Worker إلى متغير Pages:

`NEXT_PUBLIC_ATHAR_PUSH_API`

بعد حفظ المتغير يجب إعادة نشر Pages. على iPhone يجب فتح أثر كتطبيق من الشاشة الرئيسية ثم الضغط على زر تشغيل الإشعارات. على Android يكفي فتح المنصة في متصفح يدعم Web Push ومنح الإذن.
