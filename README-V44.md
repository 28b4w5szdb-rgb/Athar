# أثر V44

- أيقونة جديدة ببصمة خفيفة ترمز إلى الأثر.
- انتقال مباشر إلى السورة أو الجزء عند اختياره.
- حقل انتقال مباشر إلى رقم آية داخل السورة.
- دعم Web Push في Service Worker.
- مجلد `athar-push-worker` لخدمة الإشعارات خارج المنصة عبر Cloudflare Worker وKV وCron.

مهم: ميزات القرآن والأيقونة تعمل بعد رفع الحزمة مباشرة. إشعارات خارج المنصة تحتاج نشر Worker مرة واحدة وربط متغير `NEXT_PUBLIC_ATHAR_PUSH_API`.
