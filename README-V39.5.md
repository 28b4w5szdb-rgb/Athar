# أثر V39.5 — خوارزمية المواقيت التلقائية

- حساب جميع المواقيت محليًا حسب تاريخ اليوم وإحداثيات الكاظمية.
- تعديل زاوية فجر الصبح إلى 17.9° لمعايرة وقت الصبح بدل وضع وقت ثابت.
- استمرار الشروق والظهر والمغرب بالحساب الفلكي التلقائي يوميًا.
- لا يحتاج قسم المواقيت إلى اتصال بالإنترنت.
- الإبقاء على تحسينات الوضع الليلي من V39.3.
