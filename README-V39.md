# أثر V39 — مواقيت الصلاة (المرحلة الأولى)

- تبويب جديد للمواقيت.
- جلب مواقيت الصبح والشروق والظهر والمغرب لمدينة الكاظمية/بغداد من الموقع الرسمي للعتبة الكاظمية المقدسة.
- حفظ آخر مواقيت ناجحة محليًا.
- تنبيه قصير اختياري أثناء بقاء المنصة مفتوحة.
- لا توجد ملفات صوت خارجية ولا روابط داخل صفحات القراءة.

ملاحظة: الإشعارات بعد إغلاق المتصفح تحتاج اختبار PWA والنشر، ولا يمكن ضمانها على iOS في التشغيل المحلي.
