# أثر V45.5

## الحزمة الرئيسية
- تكبير كلمة «الكعبة» داخل بوصلة القبلة.
- تحسين نمط الاهتزاز عند الوصول إلى اتجاه القبلة على الأجهزة والمتصفحات التي تدعم Web Vibration.
- الإبقاء على السهم الأخضر ورسالة الوصول والانحراف والمعايرة.

## إشعارات الصلاة الخارجية
تم فصل خدمة Cloudflare Worker في حزمة مستقلة حتى لا تؤثر أخطاء إعداد الإشعارات في نشر الموقع الرئيسي.
تحتاج الخدمة إلى نشر مستقل وربط متغير NEXT_PUBLIC_ATHAR_PUSH_API.
