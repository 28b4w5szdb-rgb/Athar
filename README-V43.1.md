# أثر V43.1

تحديث واجهة خفيف بعد النشر:

- زر مشاركة المنصة وخيار إضافتها إلى الشاشة الرئيسية.
- أيقونة أثر الجديدة عند التثبيت.
- إخفاء حالات المحتوى من واجهة المستخدم مع بقائها في البيانات الداخلية.
- تبسيط رسائل المواقيت وحذف الرسائل التقنية المكررة.
- تبسيط ملاحظة ورد اليوم.
- حذف الملاحظة الإدارية الخاصة بمراجعة المحتوى من صفحة عن المنصة.
- الحفاظ على تصميم المنصة ورابطها العام دون تغيير.
